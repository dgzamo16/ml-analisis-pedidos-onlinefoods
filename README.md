# Análisis de pedidos de alimentos en línea con Machine Learning

## ¿De qué trata?
Análisis de datos de una empresa de entregas de alimentos en línea (OnlineFoods) 
usando algoritmos de Machine Learning para segmentar clientes y apoyar la toma 
de decisiones estratégicas del negocio.

## Tecnologías usadas
- Python
- Pandas
- Matplotlib
- K-means clustering (scikit-learn)
- Google Colab

## ¿Qué se analizó?
- Limpieza y transformación de variables de texto a numéricas
- Análisis geográfico de las zonas con mayor frecuencia de entregas
- Segmentación de clientes en 3 grupos según edad, ocupación, 
  estado civil e ingresos
- Relación entre ubicación geográfica y comportamiento de compra

## Conclusiones principales
- El cliente más frecuente es un joven de 23 años, soltero, 
  estudiante, ubicado en la zona comercial de Bangalore, India
- Los clientes mayores de 27 años en zonas residenciales usan 
  menos el servicio, representando una oportunidad de crecimiento
- Se diseñaron beneficios personalizados por grupo para aumentar 
  la frecuencia de uso del servicio
